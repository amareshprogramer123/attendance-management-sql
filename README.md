# Attendance Management System – MySQL

## 📌 Project Overview

The **Attendance Management System** is a MySQL database project designed to manage and track student attendance records.

This project demonstrates how SQL can be used to create databases, manage student information, record attendance, and retrieve useful attendance-related information using SQL queries.

## 🎯 Objectives

* Store student information
* Record daily attendance
* Track present and absent students
* Retrieve attendance records using SQL queries
* Practice database design and SQL operations
* Generate useful information from attendance data

## 🛠️ Technologies Used

* **Database:** MySQL
* **Tool:** MySQL Workbench
* **Language:** SQL
* **Version Control:** Git & GitHub

## 🚀 How to Run the Project

### Step 1: Install MySQL

Install MySQL and MySQL Workbench on your computer.

### Step 2: Open the SQL File

Open:

```text
attendance_project.sql
```

in MySQL Workbench.

### Step 3: Execute the SQL Code

Run the SQL script in MySQL Workbench to create the database, tables, insert data, and execute the queries.

## 📊 Example Queries

The project contains queries for retrieving and analyzing attendance information.

Example:

```sql
SELECT * FROM attendance;
```

You can also use queries to find attendance records based on students, dates, or attendance status.
